Pilih sumber data dulu, lalu ikuti 4 langkah.

Pick a data source first, then follow 4 steps.

Sumber dataData source

Paling mudah, ±5 menit. Siapa pun yang punya link sheet bisa melihat daftar nama.

Easiest, ~5 min. Anyone with the sheet link can see the names.

Lebih privat, ±10 menit. Data tetap di Google Sheet, tetapi sheet tidak dibagikan: website membacanya lewat skrip kecil di dalam sheet itu.

More private, ~10 min. Data still lives in a Google Sheet, but the sheet isn't shared: the website reads it through a small script inside that sheet.

2. Siapkan Google Sheet2. Set up the Google Sheet

  1. Buka sheets.new dan beri nama spreadsheet.
  2. Ganti nama tab Sheet1 menjadi Anggota. Lalu File → Impor → Upload, pilih Members-ID.csv, pilih Ganti sheet saat ini.
  3. Ganti nama contoh dengan nama anggota timmu, satu per baris.
  4. Tambah tab baru bernama Pengaturan, lalu impor Settings-ID.csv dengan cara yang sama.
  5. Di kolom B, isi Tanggal Mulai (contoh '2026-11-16, pakai petik), Jumlah Kursi, dan Kunci (teks acak, rahasiakan).
  6. Biarkan akses sheet Dibatasi. Jangan bagikan sheet ke siapa pun.
  1. Open sheets.new and name the spreadsheet.
  2. Rename tab Sheet1 to Members. Then File → Import → Upload, choose Members-EN.csv, pick Replace current sheet.
  3. Replace the sample names with your team, one per row.
  4. Add a new tab named Settings and import Settings-EN.csv the same way.
  5. In column B, fill Start Date (e.g. '2026-11-16, with the apostrophe), Seats, and Key (random text, keep it secret).
  6. Keep sheet access Restricted. Don't share the sheet.

Impor gagal? Unduh Settings-paste-ID.tsv, buka di Notepad, salin semua, tempel di sel A1.

Import failed? Download Settings-paste-EN.tsv, open it in Notepad, copy all, paste into cell A1.

3. Bagikan sheet & hubungkan3. Pasang Apps Script & hubungkan3. Share the sheet & connect3. Install Apps Script & connect

  1. Klik Bagikan → Akses umum: Siapa saja yang memiliki link sebagai Pelihat.
  2. Klik Salin link.
  3. Di Admin, pilih Google Sheet, tempel link, klik Uji & hubungkan.Muncul "Link undangan siap".
  1. Click Share → General access: Anyone with the link as Viewer.
  2. Click Copy link.
  3. In Admin, choose Google Sheet, paste the link, click Test & connect.You see "Invite link ready".
  1. Di sheet, klik Ekstensi → Apps Script.
  2. Ganti seluruh kode dengan isi Code.gs, lalu simpan (Ctrl+S).
  3. Terapkan → Deployment baru → jenis Aplikasi web. Jalankan sebagai Saya, akses Siapa saja. Klik Terapkan.
  4. Izinkan akses. Jika muncul "belum diverifikasi", klik Lanjutan → Buka (tidak aman). Ini normal untuk skrip sendiri.
  5. Salin URL berakhiran /exec. Di Admin, pilih Apps Script, tempel, klik Uji & hubungkan.Muncul "Link undangan siap".
  1. In the sheet, click Extensions → Apps Script.
  2. Replace all code with the contents of Code.gs, then save (Ctrl+S).
  3. Deploy → New deployment → type Web app. Execute as Me, access Anyone. Click Deploy.
  4. Authorize access. If you see "hasn't verified this app", click Advanced → Go to (unsafe). That's normal for your own script.
  5. Copy the URL ending in /exec. In Admin, choose Apps Script, paste, click Test & connect.You see "Invite link ready".

4. Bagikan ke anggota4. Share with members

Klik Kirim ke grup WhatsApp atau Salin link. Anggota membuka link, memilih nama, dan melihat kursinya setiap hari.

Click Send to WhatsApp group or Copy link. Members open it, pick their name, and see their seat every day.

Pengaturan bisa diubah kapan saja di sheet, link tidak berubah. Setelah mengubah Code.gs, buat Versi baru di Kelola deployment.

Change settings anytime in the sheet; the link stays the same. After editing Code.gs, create a New version in Manage deployments.

5. Kalau ada masalah5. Troubleshooting

"Google Sheet belum bisa dibaca"
Akses harus Siapa saja yang memiliki link · Pelihat, dan nama tab persis Anggota dan Pengaturan.
Tanggal kosong atau jadi angka aneh
Ketik ulang dengan petik di depan: '2026-11-16.
"Anggota … orang, kursi hanya …"
Perbesar Jumlah Kursi.
Apps Script tidak memberi data
Akses harus Siapa saja dan URL berakhiran /exec. Setelah mengubah Code.gs: Kelola deployment → pensil → Versi baru.
"Google Sheet belum bisa dibaca" · can't read sheet
Access must be Anyone with the link · Viewer, and tabs named exactly Members and Settings.
Date empty or a strange number
Retype it with an apostrophe in front: '2026-11-16.
"Anggota … orang, kursi hanya …" · too few seats
Increase Seats.
Apps Script returns no data
Access must be Anyone and the URL must end in /exec. After editing Code.gs: Manage deployments → pencil → New version.
